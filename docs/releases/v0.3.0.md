# OhMyNewTabTodo v0.3.0

## 中文

- 首页右上角现在可切换 `EN / 中文`，首次使用默认英文。语言选择保存在本机，已打开的新标签页同步更新，完整备份也包含该选择。
- 设置、导入导出、日期和错误提示提供中英文。扩展说明和工具栏标题按 Chrome 自身语言显示。
- 发布流程对同一构建进行浏览器验收和打包，并将经过 SHA-256 核对的 ZIP 上传到本 Release。

**升级：**先导出完整备份，将 ZIP 解压内容覆盖到原安装目录，再到 `chrome://extensions` 点击重新加载。不要先卸载扩展；换目录可能改变扩展身份和本地存储。

**限制：**尚无 Chrome 跨设备自动同步，也未上架 Chrome Web Store；仍需手动安装和更新。恢复点不能代替外部备份。

## English

- Switch between `EN / 中文` on the homepage. English is the first-use default. The choice is stored locally, updates other open tabs, and is included in full backups.
- Settings, transfers, dates, and error messages are available in both languages. The extension description and toolbar title follow Chrome's language.
- The release workflow tests and packages one build, then uploads the SHA-256-verified ZIP to this Release.

**Update:** Export a full backup, replace the files in the existing installation directory with the ZIP contents, then click Reload at `chrome://extensions`. Do not uninstall first; changing directories may change the extension identity and local storage.

**Limits:** There is no automatic Chrome cross-device sync or Chrome Web Store listing. Installation and updates remain manual. Recovery points do not replace external backups.
