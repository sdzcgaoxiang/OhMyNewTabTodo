# OhMyNewTabTodo v0.4.0

## 中文

- 新增卡片时可设置创建时间。打开表单时默认填入本地当前日期和时间，精确到秒；也可为补录事项指定过去的时间。
- 创建时间沿用现有数据字段，旧卡片和备份格式不变；编辑卡片不会重写原创建时间。

**升级：**建议先导出完整备份。将 ZIP 解压内容放入原安装目录，再到 `chrome://extensions` 点击重新加载；不要卸载旧扩展，也不要改用其他目录。正常原位更新无需再导入备份。

**限制：**尚未上架 Chrome Web Store，仍需手动安装和更新；不提供跨设备自动同步。恢复点不能替代外部备份。

## English

- Set a creation time when adding a card. The form defaults to the current local date and time, to the second; you can choose an earlier time for backfilled tasks.
- The existing creation-time field is used, so old cards and backup formats are unchanged. Editing a card preserves its original creation time.

**Update:** Exporting a full backup first is recommended. Extract the ZIP into the existing installation directory, then click Reload at `chrome://extensions`. Do not uninstall or switch directories. A normal in-place update needs no backup import.

**Limits:** The extension is not yet on the Chrome Web Store, so installation and updates remain manual. There is no cross-device sync. Recovery points do not replace external backups.
