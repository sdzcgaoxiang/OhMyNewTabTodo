# OhMyNewTabTodo v0.5.0

## 中文

- 截止日期默认不设置；点击“设置截止日期”时填入当天，可修改或移除。
- 参考 iPhone 提醒事项：只设置日期的任务默认当天 **09:00** 提醒，可在“设置 → 提醒”调整时间或关闭全天提醒；设置具体时间的任务在截止时间提醒。
- 后台提醒不依赖任务页面保持打开；完成、删除或清除日期会取消待发提醒。同一次截止安排正常运行及后台重启后去重，已登记但停机期间错过的提醒恢复后补发。
- 新增可选的本地外部只读接口：在“设置 → 导入 / 导出 → 外部工具读取”中选择事先创建的空白 JSON 文件，插件在数据保存后把只读快照写入该文件，供 `omntt` CLI、配套 Skill 或其他本机工具读取。CLI 与 Skill 从仓库源码获取，不包含在扩展 ZIP 中。
- 重绘扩展图标与页面操作图标，改用薄荷绿叠卡标识和矢量图标。
- 保留旧任务、旧 ID、未知业务字段与备份兼容；修复恢复旧版恢复点时可能误报保存失败的问题。

**新增权限：**`alarms` 与 `notifications`，仅用于本机调度和系统通知，不增加网络请求。通知中心可能显示任务标题和截止信息，不显示任务描述。首次升级不集中补发过去日期的历史任务；当天已经到点的任务可能立即提醒。

**升级：**先导出完整备份，将 ZIP 解压内容放入原安装目录，然后到 `chrome://extensions` 重新加载并检查新增权限。不要卸载旧扩展或切换安装目录。请保持 Chrome 运行，并在浏览器及系统设置中允许 Chrome 通知。

**限制：**休眠、免打扰或浏览器关闭可能延迟提醒。操作系统横幅、声音和锁屏显示仍需在目标系统确认；极端崩溃窗口可能重复展示同一通知。投递历史不随备份转移，删除/清空后恢复任务可能再次提醒。不包含重复、提前、位置或紧急闹钟，不与 iPhone 同步。外部快照包含明文任务、不是备份，浏览器重启后可能需要分别重新授权读取和写入；真实系统文件选择与重启后的授权恢复只在 macOS / Chromium 156 验证过。仍需手动安装更新，未上架 Chrome Web Store，无跨设备自动同步。

## English

- Due dates remain unset until “Set due date” fills today. Edit or remove the date as needed.
- Following iPhone Reminders, date-only tasks notify at **09:00** by default. Adjust or disable all-day reminders in Settings → Reminders; tasks with a specific time notify at their due time.
- Background reminders work with task pages closed. Completion, deletion, and date removal cancel pending reminders. Persistent deduplication covers normal operation and worker restarts; registered reminders missed during downtime are caught up.
- Added an optional local read-only external interface: select an empty JSON file you created beforehand under Settings → Import / Export → External tool access, and the extension writes a read-only snapshot to it after persisted changes for the `omntt` CLI, the companion skill, or other local tools. The CLI and skill come from the repository source and are not included in the extension ZIP.
- Redrew the extension icon and page action icons with a mint stacked-card mark and vector glyphs.
- Preserves legacy tasks, IDs, unknown business fields, and backup compatibility. Fixes false failure reports when restoring older recovery points.

**New permissions:** `alarms` and `notifications` for local scheduling and system notifications, with no additional network requests. The notification center may show task titles and due information, but not descriptions. Initial upgrades skip historical past dates; tasks already due today may notify immediately.

**Update:** Export a full backup first. Extract the ZIP into the existing installation directory, then reload at `chrome://extensions` and check the new permissions. Do not uninstall or switch directories. Keep Chrome running and allow Chrome notifications in both browser and system settings.

**Limits:** Sleep, Do Not Disturb, or closing the browser can delay reminders. OS banners, sounds, and lock-screen presentation still require target-system verification; an exceptional crash window can redisplay the same notification. Delivery history is not transferred in backups, so restoring deleted/cleared tasks can notify again. Repeating, early, location, urgent alarms, and iPhone synchronization are not included. External snapshots contain plaintext tasks and are not backups; after a browser restart, read and write permission may need to be granted again, and the real file picker plus post-restart re-authorization were verified only on macOS / Chromium 156. Installation and updates remain manual; there is no Chrome Web Store listing or automatic cross-device sync.
