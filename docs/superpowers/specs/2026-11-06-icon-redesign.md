# 图标重绘

重绘扩展标识与页面操作图标。参考 NewTabTodo 0.2.0 的入口语义，独立绘制几何形状。考虑过保留文字符号并统一字体，以及使用内联 SVG。选用 SVG，使小尺寸线条在不同系统和主题中保持一致。

扩展标识以深绿底、低对比度的后卡、薄荷绿前卡和完成勾为主体，提供 16、32、48、128 像素的透明 PNG，前后卡用柔和渐变、边缘高光和接触阴影区分层次，16 像素版省略卡片高光和阴影，页面品牌标识使用同一矢量稿。页面操作图标随文字颜色适配主题，已有可访问名称、按钮行为和文字标签保留。通过扩展浏览器测试检查图标与按钮语义，并核对产物尺寸。

原版对照基线为 Firefox 版 0.2.0。当前工作区无完整的参考安装包，下载也未完成，因此原版图形的逐项对照待核验。新图形按当前项目中各入口的操作含义绘制。
