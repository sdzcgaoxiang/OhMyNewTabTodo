# Chrome 商店提交材料

目标：为下一版本准备首发商店素材，让 GitHub Release 和 Chrome Web Store 使用同一份发行 ZIP。素材使用项目自有设计与合成截图，说明新标签页覆盖、本地存储和同步限制；隐私信息应与现有实现一致。

扩展包包含 16、32、48、128 像素 PNG 图标，manifest 声明图标，打包白名单只允许指定图标。商店资料包含中英文介绍、用途与权限说明、隐私填写提示、1280×800 截图和 440×280 宣传图。现有 0.4.0 GitHub Release 的历史记录保持原样；本地测试包不同于历史发行包。下一版通过 GitHub Release 发布经验证的 ZIP，商店上传该 ZIP 的原文件。注册资料、最终隐私披露与提交由开发者核实。
