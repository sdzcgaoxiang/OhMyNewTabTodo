# 截止日期与提醒设计

状态：2026-11-04 用户确认继续，已实现并通过本地验收；当前为未发布开发分支。

## 意图与已确认需求

新卡片默认没有截止日期。用户点击设置日期时，默认填入操作当天的本地日期，允许修改或清除。提醒规则参考 iPhone 提醒事项的日期、时间和全天提醒，不扩展到整个提醒事项应用。

Apple 官方说明：只设日期、未设时间的提醒默认在当天 09:00 通知，可在设置中调整全天提醒时间；设置具体时间则按该时间提醒。参考：https://support.apple.com/en-us/102484 。

## 方案

沿用用户要求的系统通知方案：Chrome 后台使用 `chrome.alarms` 调度，使用 `chrome.notifications` 发送本机通知。关闭任务页面后仍可提醒。日期和时间继续使用现有 `dueDate` / `dueTime` 字段，所有任务修改继续经过后台单写入口。

考虑过仅在页面内显示提醒：依赖页面一直打开，不符合离开页面后接收提醒的预期。考虑过外部推送服务：会引入账号、网络和服务器，与本地优先架构不符。因此本功能只有后台本机通知这一种合适的实现方式。

## 用户可见行为

- 新建任务默认无日期、不安排提醒。编辑无日期的旧任务也不自动添加日期。
- 无日期时提供“设置截止日期”操作；点击时按此刻的本地日历填入今天。未保存草稿不安排提醒。
- 开启日期后可以修改日期、填写具体时间，或移除截止日期；移除日期同时清除时间。
- 只设日期时属于全天提醒，默认当天 09:00 通知。设置中可开启/关闭全天提醒，并调整统一时间；关闭全天提醒不影响有明确时间的任务。
- 设置具体时间后，在截止日期的该时间通知。日期和时间按当前设备本地时区解释，保持现有本地日历语义。
- 通知显示任务标题与截止信息，使用当前界面语言；点击通知打开扩展任务页面。任务描述不进入通知。
- 完成、删除、移除日期或删除所属看板后，取消未发出的提醒。隐藏看板不取消提醒。
- 同一任务的同一次截止安排只通知一次；页面刷新、多个标签页和后台重启不重复通知。修改截止安排可生成一次新的提醒；仅改标题、移动看板、切换语言不会重新通知。
- 不自动给旧卡片添加日期，不删除旧字段、旧 ID 或未知导入字段。

## 平台边界与补发（实现建议）

- Chrome 必须运行、通知必须被允许。电脑休眠、浏览器关闭或系统通知策略可能延迟通知，不能保证秒级准点，也不能绕过免打扰。
- 系统通知和本机存储不支持跨接口原子提交；极端情况下，在通知已发出但投递记录写入前崩溃，重试可能再次展示同一条通知。使用稳定通知 ID 减少重复，但不承诺崩溃窗口内的严格恰好一次语义。
- 后台维护待发计划和已发记录。对已登记、在休眠或停机期间错过的提醒，恢复运行后补发一次。
- 首次升级/导入不集中补发历史过期任务；只为尚未到点或当天到点的任务建立新提醒。当天新增但已过提醒时间的任务保存后提醒一次。过去日期仍显示过期，不新发历史通知。
- 已完成后重新打开的任务若同一截止安排已经通知，不重复通知；可通过更改截止安排设置新提醒。
- 不提供重复提醒、提前提醒、位置提醒、紧急闹钟、iCloud 同步或 iPhone 联动。

## 数据与架构（实现建议）

- 保留 schemaVersion 1 和旧卡片日期字段的兼容性。新增全天提醒设置要有缺失时默认值、类型校验、完整备份往返和恢复测试；旧备份缺失时使用默认行为。未知业务字段继续保留。
- 本机通知投递记录独立于任务业务数据，不进入导出文件或恢复快照。所有记录的写入由后台执行；不改变任务内容或制造编辑冲突。
- 使用少量闹钟驱动最近截止提醒与定期校正，避免每张卡片一个闹钟的数量限制。监听安装、启动、持久化状态变化，并在后台唤醒时恢复调度；只处理本扩展命名的闹钟。
- 发送前重新确认任务存在、未完成、截止安排仍然一致。调度与投递串行，避免多次事件同时触发重复通知。
- 通知失败不能回滚已经成功保存的任务；保留待发计划并在后续事件重试。设置中说明通知被禁用时的恢复方法。
- 额外申请 `alarms` 和 `notifications` 权限。通知图标独立绘制或使用仓库自有素材，不使用原版素材，不增加网络请求。
- 开发网页预览仍可编辑日期和设置，但明确系统提醒只在正式扩展内生效。

## 规格、测试与交付

遵循规格先行 TDD：先观察默认日期、全天时间、具体时间、取消、一次投递、失败重试和重启恢复的失败测试，再实现。

单元测试覆盖本地日期、午夜、无效旧日期、全天开关、设置兼容、通知投递去重、改期、完成/删除和后台重启。扩展验收覆盖打开表单后点击才填入今天、清除日期、保存持久化、跨标签页一致性、后台闹钟/通知及无页面时的提醒流程。Chrome/操作系统真实通知展示与免打扰边界需如实记录，自动化不可冒充人工验收。
