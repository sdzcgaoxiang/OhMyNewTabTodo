# 双语升级特性与文档维护设计

用户已确认：README 核心升级入口、独立特性对比、迁移路径，中英双语；明确以后每个版本需要刷新哪些文档。

采用 README.md / README.en.md 与 docs/features.md / docs/features.en.md 成对维护。只扩展 README 会掩盖完整对比；只写独立文档不利于首次访问者发现升级价值，因此采用入口摘要加详细特性的组合。

对比基线固定为已审计的 NewTabTodo 0.2.0；新版当前为 0.1.0。区分保留功能、已实现升级、限制和证据，不把新版开发期缺陷写成原版缺陷，不承诺官方关联、所有历史格式或跨设备同步。英文文档明确当前产品界面为中文。

docs/releasing.md 提供双语发布文档清单：每次发布检查 CHANGELOG、两种 README、两种特性说明、新的版本验收记录及 Release；按变化检查隐私、规格、贡献指南、AGENTS、截图、依赖许可证。历史审计和旧版本验收不重写。PR 模板与贡献指南、AGENTS 链接同一清单。

使用既有合成看板截图及独立临时 Chromium 中生成的导入预览截图；不得使用私人输入。仅文档和贡献流程变更，不升级产品版本、不重发安装包。

验收：逐项核对实现/测试/原版审计；双语章节和限制一致；相对链接和图片存在；版本与命令正确；工作区不包含私人样例。
