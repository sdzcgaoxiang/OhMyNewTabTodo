# OhMyNewTabTodo v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build a loadable local-first extension with familiar NewTabTodo behavior and reliable legacy import/export.
**Architecture:** React UI, original-shaped plain-object model, one chrome.storage.local state record, serialized background mutations, change notifications. Pure transfer/model modules tested independently.
**Tech Stack:** JavaScript ES modules, React, Vite, Node test runner, Playwright, Manifest V3.
**Spec:** docs/superpowers/specs/2026-10-27-v1-design.md

## Global Constraints

- Independently authored code/assets; no bundled proprietary code or user data.
- No cross-device sync, backend, telemetry, or IndexedDB in v1.
- Keep boards/cards/boardOrder structure and preserve imported unknown fields.
- No success before persistence; non-destructive preflight; no silent truncation.
- Only the background writes production state; pages never persist whole stale snapshots.
- reference/ and private-backups/ remain ignored; test data is synthetic.

## Review Focus

- Malformed imported object IDs/references must never corrupt current state (Task 1).
- Empty vs missing bookmark fields and more than 15 entries must roundtrip (Task 1).
- Two pages edit the same/different cards; conflicts must preserve draft and existing changes (Tasks 2/3).
- Import/recovery preview becomes stale after another change; commit must be rejected (Task 2).
- Storage failure or worker restart cannot yield false success or incomplete persisted state (Task 2).
