# 原版拖拽体验迁移验证

日期：2026-10-28。状态：未发布开发版；不改变已发布 v0.1.0 安装包。

## 原版证据

从 [Mozilla 官方 NewTabTodo 0.2.0 扩展包](https://addons.mozilla.org/en-US/firefox/addon/new-tab-todo/versions/)读取界面代码与样式；包的 SHA-256 为 `58e6c95fbda8da70ddc2a780f4b5283d448b2f48fd4ba7edd4a67baa6dcbc17c`。包内 `DragDropContext`、`Droppable`、`Draggable` 和 `placeholder` 确认了原版的卡片纵向排序、跨列移动与看板横向排序结构。列表悬停状态和拖动卡片阴影也在样式中确认。原版包仅保存在临时目录，不进入仓库。

此前 Chrome 0.2.0 安装包的哈希与 Mozilla 包不同，且当前已不在本机。两者版本相同不代表视觉或每个边界行为完全相同；用户原版 Chrome 的逐项视觉对照仍待实测。

## 新版验证

- `npm run check`：格式检查、35 项单元测试、构建和 25 项隔离 Chromium 浏览器测试通过。
- 浏览器测试覆盖卡片跨列、键盘列内排序、看板横向排序、空列、无效区域取消、隐藏完成卡片禁止拖动、隐藏项索引、横向溢出及刷新后持久化。
- 拖动中断言目标列出现库提供的占位、列表背景变化，拖动卡片的阴影与静止状态不同。人工查看合成数据截图，确认卡片跟随指针、目标列高亮且占位可见。
- 数据提交仍走 `card.move` / `board.move` 和后台写入器；预览过程中不写入存储。
- 延迟后台写入时，松手后立即显示新顺序；保存失败则恢复已持久化顺序并显示错误。
